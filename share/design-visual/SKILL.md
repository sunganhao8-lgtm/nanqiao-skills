# design-visual — 设计视觉

## 触发条件

- "画个架构图 / 流程图 / 时序图"
- "做个信息图 / 海报 / PPT"
- "转成 HTML / 公众号文章"
- "画个漫画 / 知识漫画"

## 工具集

### A. SVG 图表（architecture-diagram / baoyu-diagram）
深色主题 SVG 架构/流程/时序图。输出独立 .svg 文件。

### B. 手绘风格图（excalidraw）
JSON 格式手绘架构/流程图，适合技术文档。

### C. 信息图 / 卡片图（baoyu-infographic）
21 种布局 × 21 种风格，适合小红书/社交媒体图文卡片。

### D. PPT 幻灯片（baoyu-slide-deck）
从内容生成逐页 PPT 图片。

### E. Markdown → HTML（baoyu-markdown-to-html）
转 WeChat 兼容 HTML，支持代码高亮/数学公式/Mermaid。

### F. 文章配图（baoyu-article-illustrator）
分析文章结构，配适图 Type × Style × Palette。

### G. 知识漫画（baoyu-comic）
多格教育漫画，批量图片生成。

## 输出
- 独立 HTML / SVG / 图片文件
- 文件命名含功能前缀 + 时间戳
