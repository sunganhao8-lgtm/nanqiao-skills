# wechat-style-analyzer — 对话风格分析

## 触发条件

- "分析我微信聊天风格"
- "给我做一个我的 persona prompt"
- "把聊天记录训练成 LLM 风格"
- "分析 XX 群的对话风格"
- "提取我的说话习惯"

## 前置

- 已有 `export/reports/report_{date}.md`（用 `wechat-chat-export` 导出）
- 建议多日数据（至少 3-7 天）以保证画像稳定

## 工作流

### Step 1：收集样本

**最少**：单日单群（粗画像）
**推荐**：3-7 天同群（中等画像）
**理想**：多群多日（强画像）

如果样本不够，提示用户：
```
"我至少需要 X 条你的消息才能稳定画像。目前有 Y 条，建议再导出 N 天。"
```

阈值建议：
- < 50 条：粗画像（不推荐用作 persona）
- 50-200 条：基础画像
- 200-1000 条：稳定画像
- > 1000 条：高质量画像

## 实战数据参考

基于 17257 条消息（15152 条有效纯文本）的实际分析结果：

| 维度 | 结果 |
|------|------|
| 平均句长 | 9.6 字（79% 短句） |
| 句尾习惯 | '了'(1903次)、'的'(1117次)、'？'(701次) |
| 情感句尾 | '呢'(347)、'吗'(334)、'吧'(313) |
|  表情包式标点 | 高频：`。` `？` `~` `！` |
| 最常说的词 | [破涕为笑] (268)、是的(178)、好的(136) |
| 回应型 | 嗯呢(83)、嗯嗯(62)、OK(67)、好的(135) |
| 感叹型 | 我靠(53)、卧槽(42)、哈哈(51) |
| 称呼技巧 | 哥/姐尾缀（俊哥、嘉磊哥、朱姐、家清姐） |

### Step 2：分段提取你的消息

**关键**：只分析"我"的消息（不是整个群对话），从 MD 中过滤出自己发的话。

```python
# 伪代码
my_messages = []
for line in md_content:
    if line matches "[HH:MM:SS] 我: " or "[HH:MM:SS] {你的微信名}: ":
        my_messages.append(extract_text(line))
```

通过 `WECHAT_SELF_NAME`（.env 中配置）识别"我"。

### Step 3：5 维度分析

把过滤出的消息列表喂给 LLM，按 5 维度输出：

#### 维度 1：句式习惯

- 平均消息长度（短句/中长句/长段）
- 句尾标点习惯（句号/省略号/感叹号/不带标点）
- 拆分/不拆分的偏好（一次发 3 句 vs 一次发 1 段）
- 标点强度（`！！` `???` `~` 等表情包式标点）

#### 维度 2：词汇与口头禅

- 高频词（top 30 词）
- 专属口头禅（如"绝了""笑死""确实""哈哈哈"）
- 缩略语（"xswl""yyds""破防了"）
- 网络梗/特定表达
- 称呼（怎么叫人，叫长辈/平辈/小辈）

#### 维度 3：情绪与反应模式

- 默认语气（冷静/热情/毒舌/吐槽/温柔）
- 表达情绪的方式（直白/反讽/阴阳/撒娇）
- 笑点/哭点/怒点的触发词
- 沉默/已读不回的概率

#### 维度 4：话题参与度

- 主动开话题 vs 回应别人比例
- 擅长的话题（如技术/八卦/工作/情感）
- 退出话题的信号
- 信息密度（爱不爱写细节）

#### 维度 5：场景切换

- 不同群用不同风格（工作群 vs 朋友群 vs 家人群）
- 早中晚不同时段语气变化
- 长辈在场 vs 平辈的礼貌度调整

### Step 5：交付与使用

输出文件位置：

```
export/personas/persona_{user_name}_{date}.json
```

后续用法：
- **半自动回复**：把 `persona_prompt` 喂给 LLM，让它生成草稿（你自己确认后发）
- **风格迁移**：写作时把 persona_prompt 注入 system prompt
- **训练数据**：把 `writing_samples` 整理成 fine-tune 数据集

## 红线

- [ ] 不分析别人（只分析"我"）
- [ ] 样本量 < 50 主动提示画像质量低
- [ ] 敏感信息（身份证/手机/密码）必须 mask 掉再分析
- [ ] 不上传 persona JSON 到云端
- [ ] persona prompt 不直接拿去做"自动回复"——必须人工把关

## 隐私

- 输入数据：本地 `export/reports/`（你控制）
- 分析过程：LLM 上下文（不持久化）
- 输出：本地 `export/personas/`（你控制）
- **绝不**把聊天记录上传到云端训练

## 进阶：多群差异分析

如果导出多个群，可对比输出「场景风格地图」：

```
| 群     | 默认句长 | 口头禅   | 语气     | 话题参与 |
|--------|----------|----------|----------|----------|
| 工作群 | 中句     | 收到/好  | 严肃     | 低       |
| 朋友群 | 短句     | 笑死/yyds | 毒舌     | 高       |
| 家人群 | 极短     | 嗯/好的  | 温顺     | 中       |
```

用于：
- 自己意识到不同场景下人格切换
- 写「自动回复」时按群选择 persona 子集
