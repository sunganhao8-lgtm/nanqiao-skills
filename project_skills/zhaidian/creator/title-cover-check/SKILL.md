# 宅电标题封面检查 skill

## 触发条件

- "帮我检查这个标题"
- "封面这样行不行"
- "发布前检查"
- "标题封面检查"
- 用户写完脚本/笔记后要求审核

## 输入

- 标题（必填）
- 正文前 50 字
- 封面描述或封面图路径（可选）

## 工作流

### 第一轮：标题检查（SEO + 点击率 + 合规）

**SEO 检查**：
- [ ] 标题含有关键搜索词（电竞房/游戏房/装机/显示器等）
- [ ] 地域词（上海/临港/浦东/区域）适合出现
- [ ] 长度 6-20 字
- [ ] 无小红书违禁词（"第一"/"最"/"全国"）

**点击率检查**：
- [ ] 有钩子（反共识/数字/悬念/对比/结果）
- [ ] 有具体承诺/信息差（不是"XX 的注意事项"）
- [ ] 跟同页面笔记有差异化

**评分**：1-10

### 第二轮：封面检查（宅电品牌规范符合度）

**品牌规范**：
- [ ] 主色 = 深空灰（#1A1A2E）/ 冷蓝（#4A9EFF）/ 赛博紫（#B026FF）
- [ ] 暗色科技 / 灯效 RGB 点缀
- [ ] 设备特写清晰
- [ ] 玩家背影/侧影/手部（不画正面人脸）
- [ ] 关键数字冷蓝/紫加粗
- [ ] 角标 宅电 ZHAIDIAN 露出
- [ ] **无暖橙治愈系**（那是宅咪）

**小红书适配**：
- [ ] 3:4 竖图
- [ ] 文字在上半部分（折叠后可见）
- [ ] 非纯设备图（必须配文字/数据）

**评分**：1-10

### 第三轮：综合输出

```
【标题封面检查报告】
检查日期：YYYY-MM-DD

📌 标题
原文 / SEO 评分 / 点击率评分 / 综合评分
问题 → 修改建议
优化后标题：{改写}

🎨 封面
品牌规范符合度 / 小红书适配度
问题 → 修改建议

🏁 发布就绪度：{就绪 / 小修可用 / 建议重写}
```

## 红线

- [ ] 每项问题有具体修改建议，不说"挺好的"
- [ ] 没有封面信息就说"未提供"
- [ ] 标题改写保留原意，不改成另一个选题
- [ ] 检查后如果有修改 → 再跑一轮 humanizer-zh
