# 宅电评论洞察分析 skill

## 触发条件

- "帮我分析这些评论"
- "这些弹幕能出什么选题"
- "评论洞察"
- "从评论区挖选题"
- 用户给了一批评论/弹幕原文

## 输入

原始评论/弹幕/留言文本（可以是 JSONL、纯文本段落、截图里的 OCR 文本）

## 工作流

### Step 1：数据准备

如果用户没给原文：
- `mcp_chrome_devtools_*` → 抓小红书/抖音评论区
- `web_search` → 搜索相关笔记的评论
- 用户直接贴文本

### Step 2：AI 分类（每条都要过）

**宅电专属 4 分类**：

| 分类 | 典型表达 | 示例 |
|------|----------|------|
| **A. 痛点** | 我家XX/想XX但不会 | "想在家里做电竞房但不会选设备" |
| **B. 需求** | 有没有XX/想找XX | "上海有上门装游戏房的吗" |
| **C. 选择** | XX和XX哪个好 | "2K 144Hz 还是 4K 60Hz" |
| **D. 吐槽** | 上次XX太差/踩雷 | "上次买的电竞椅三个月就塌了" |

每条评分两个维度 1-5：
- **痛点强度**：1=随口说 / 3=真焦虑 / 5=不解决会出问题
- **可回答度**：1=无解 / 3=有标准答案 / 5=能直接转化为宅电服务

### Step 3：选题转化

筛选规则：
- **痛点 ≥ 3 且 可回答度 ≥ 4** → 进选题池（优先）
- **痛点 ≥ 3 且 可回答度 = 3** → 进观察池
- 其余 → 存档备查

对每个进选题池的评论，生成：
- **选题标题**：改写为小红书标题
- **切入角度**：用宅电的定位怎么回答
- **内容形式建议**：图文/视频/合集

### Step 4：输出

```
【评论洞察报告】
数据来源：{来源}
分析时间：YYYY-MM-DD HH:mm
样本量：N 条

📊 分类统计
- 痛点类：N 条（占 X%）
- 需求类：N 条（占 X%）
- 选择类：N 条（占 X%）
- 吐槽类：N 条（占 X%）
- 平均痛点强度：X.X
- 平均可回答度：X.X

🔥 选题池（痛点≥3 & 可回答度≥4）— N 条
1. 原文：{原文}
   选题标题：{改写}
   切入角度：{宅电角度}
   推荐形式：{图文/视频}

2. ...

👀 观察池（痛点≥3 & 可回答度=3）— N 条
...

💡 本周选题推荐（Top 3）
1. {标题} — {理由}
2. {标题} — {理由}
3. {标题} — {理由}
```

## 红线

- [ ] 每条原文**必须标记来源**
- [ ] 不编造用户没说的痛点
- [ ] 选题标题改写**保留原问题的真实感**
- [ ] 不在输出里写"宅男/男玩家"等性别限定
