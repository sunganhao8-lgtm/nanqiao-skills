# 宅电选题评分 skill

## 触发条件

- "帮我看看这个选题值不值得做"
- "这个选题能火吗"
- "选题评分"
- 用户提交了电竞房/游戏相关选题关键词

## 输入

**宅电专属的选题类型**：
- 上门电竞房搭建服务（"在家做电竞房""上门装游戏房"）
- 设备选购（"电竞显示器推荐""2K 144Hz 怎么选"）
- 空间改造（"5 ㎡ 做电竞房""次卧改书房"）
- 设备避坑（"电竞椅智商税""网红电竞桌踩雷"）
- 教程类（"第一次装机""显卡挑选指南"）

## 工作流

### Step 1：搜索量验证
- `web_search` 搜选题关键词，记录搜索结果量级、爆款笔记、时效性、长尾机会
- 评分 1-10（10=黄金赛道，1=没人搜）

### Step 2：痛点强度评估
- 这个选题对应的真实焦虑（怕踩坑/不会选/不会装/不会改造）
- 用户会为这个痛点主动搜索吗？
- 评分 1-10

### Step 3：竞争度分析
- 同赛道对手做这个选题的频次和水平
- 评分 1-10（10=没人做，1=头部垄断）

### Step 4：转化潜力评估
- 看完笔记自然的下一步（咨询/收藏/划过）
- **宅电 0→1 钩子必选 ① 咨询导向**（评论扣【城市+房型】）
- 评分 1-10

### Step 5：可执行度评估
- 宅电作为服务商能不能拍/写/出
- 评分 1-10

## 宅电业务边界检查

- [x] 跟电竞房搭建/游戏/家居改造/设备选型直接相关？
- [x] 能在笔记里自然植入宅电服务？
- [ ] 不相关/硬蹭 → 扣 3 分

## 输出格式

```
【选题评分报告】
选题：{题目}

维度评分：
🟢 搜索量：X/10 — {说明}
🟢 痛点强度：X/10 — {说明}
🟢 竞争度：X/10 — {说明}
🟢 转化潜力：X/10 — {说明}
🟢 可执行度：X/10 — {说明}

综合评分：X/50
推荐等级：{强烈推荐 / 推荐 / 观望 / 放弃}

选题方向建议：
- {优化方向 1}
- {切入角度 1}
- {风险点提醒}

适合的笔记形式：{图文 / 短视频}
对应节日/节点：{如有}
```

## 红线

- [ ] 不写性别限定词
- [ ] 不写"两人团队/小工作室"
- [ ] `date` 查当前真实日期
- [ ] 0→1 阶段钩子 = 咨询导向，不是收藏
- [ ] 宅电的痛点要具体（不是"想要好游戏体验"）
