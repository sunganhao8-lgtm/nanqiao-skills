# 宅电视觉内容设计 skill

## 触发条件

- "帮我设计配图方案"
- "这套笔记配什么图"
- "视觉设计"
- "出图方案"
- "帮我写图片 prompt"
- 写完笔记正文后需要配图

## 输入

- 笔记正文 / 脚本
- 笔记形式（图文/视频封面）
- 可选：用户对风格的偏好

## 工作流

### Step 1：分析笔记内容，确定配图结构

**图文笔记（9 图标准结构）**：
| 图号 | 功能 | 说明 |
|------|------|------|
| 图1 | 封面钩子 | 改造后效果 + 关键数字，决定打开率 |
| 图2-3 | 改造前/后对比 | 反差 = 直观价值 |
| 图4-5 | 设备特写 | 显示器/主机/灯效特写 |
| 图6-7 | 细节/过程 | 走线/桌面/收纳 |
| 图8 | 价格/方案表 | 报价分层 + 服务范围 |
| 图9 | 品牌收尾 | 角标 + 金句 |

**视频笔记（仅封面图）**：
- 1 张封面（3:4 竖图、改造效果 + 文字钩子）

### Step 2：每张图的视觉方案

对每张图输出：
```
【图 N：{功能说明}】
场景：{一句话场景描述}
核心元素：{显示器/主机/桌面/RGB 灯效/电竞椅/游戏主机}
配色：{深空灰 / 冷蓝 / 赛博紫 / 暖橙提示}
文字覆盖：{文字内容+字体+颜色+位置}
参考素材引用：{是否引用 logo.png / 风格锚点图}
风格要求：{暗色科技 / 灯效 RGB / 3D 立体}
```

### Step 3：出图 prompt 生成

每张图输出出图用的 prompt：
```
## Prompt
{中文 prompt，豆包/即梦用}

## 参数
- 比例：3:4
- 风格参考：暗色科技，RGB 灯效，赛博朋克
```

### Step 4：输出汇总

```
【宅电视觉设计方案】
笔记标题：{标题}
出图数量：N 张

📐 出图方案总览
| 图号 | 功能 | 场景 | 核心元素 | 配色 | 文字 |
|------|------|------|----------|------|------|

📝 Prompt 清单（按顺序生成）
1. cover-{关键词}.md ↔ cover-{关键词}.png
2. card-01-{关键词}.md ↔ card-01-{关键词}.png
3. ...

🖼️ 参考素材（出图时必传）
- 宅电 logo（如已建立）
- 风格锚点图（如已建立）

⚠️ 出图后必查清单
- [ ] 每张图符合宅电品牌视觉规范
- [ ] prompt .md 与图片同目录
- [ ] 角标 宅电 ZHAIDIAN 露出
- [ ] 没有 AI 画人脸（玩家背影可，全脸不画）
```

## 宅电品牌视觉（待建立）

**主色候选**（建规范时确认）：
- 深空灰 `#1A1A2E`（主背景）
- 冷蓝 `#4A9EFF`（强调色 / 灯效）
- 赛博紫 `#B026FF`（RGB 灯效 / 标题）
- 电光白 `#FFFFFF`（高光 / 数字）
- 暖橙提示 `#F4B860`（保留宅系列记忆点，限按钮/CTA）

**风格要求**：
- 暗色科技 / 赛博朋克
- RGB 灯效点缀（不喧宾夺主）
- 设备特写清晰（显示器/主机/桌面/椅子）
- 玩家**背影或侧影**（不画正面人脸）
- 关键数字深蓝/紫加粗加大

**禁用**：
- 莫兰迪灰调
- 暖橙治愈系（那是宅咪，宅电不做）
- 手绘 doodle
- 平面 2D
- 正面人脸

## 红线

- [ ] 不设计"品牌定调/团队照"类画面（0→1 不需要）
- [ ] 每张图的 prompt 都基于品牌规范
- [ ] 玩家只画背影/侧影/手部，不画正面
- [ ] 封面必须有标题文字
- [ ] prompt .md 与图片同目录
