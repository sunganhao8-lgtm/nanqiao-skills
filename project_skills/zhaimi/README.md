```

        │
        ▼
┌─────────────────────────────┐
│  orchestrator/ 内容调度器    │  ← 总入口
│  决定走模式A/B/C             │
└──────────┬──────────────────┘
           │
    ┌──────┼──────┐
    ▼      ▼      ▼
 模式A  模式B  模式C
 完整   爆款   评论→
 创作   改造   选题
           │
           ▼
    ┌──────────────┐
    │  research/   │  ← 选题/竞品/拆解/洞察
    │  vidiator/   │  ← 脚本/视觉
    │  creator/    │  ← 检查
    └──────┬───────┘
           ▼
      完整内容包
```
