# zhaimi-vidiator — 内容创作技能包

> 适用 profile：vidiator
> 依赖公用技能：`image-gen`、`browser-automation`、`content-processing`

## 触发条件

用户在以下场景调用 vidiator profile：
- "帮我把这个选题写成笔记"
- "写个脚本 / 出文案"
- "设计配图 / 出图方案"
- "视觉设计"
- "写 prompt"

---

## 技能 1：脚本写作（script-writing）

### 触发
- "写文案 / 出脚本 / 写成小红书笔记"

### 输入
- 选题方向 / 关键词
- 可选：参考爆款笔记（来自 research 的拆解结果）

### 流程

**Step 1**：确定笔记形式（图文/视频）
- 图文：攻略/清单/对比/科普
- 视频：过程展示/服务实拍
- 默认图文（0→1 成本更低）

**Step 2**：标题设计（3 个版本，排序推荐）
- 标注：字数、钩子类型、SEO 词命中
- 排序权重：数字精准 > 地域精准 > 反共识 > 痛点

**Step 3**：正文结构（500 字以内）

```
1️⃣ 开头钩子（前 2 行）— 提问/反常识/具体场景
2️⃣ 场景痛点（拉共鸣）— "被问最多的就是..."
3️⃣ 解决方案 / 对比（干货核心）
4️⃣ 宅咪怎么做（行为锚点，不堆形容词）
5️⃣ 人设短版（一句话）
6️⃣ CTA / 私域钩子（评论区扣【关键词】）
7️⃣ 小提醒（打消顾虑）
8️⃣ 结尾金句
```

**Step 4**：如果视频 → 分镜表
```
| 镜号 | 时长 | 画面 | 配音 | 字幕 |
```

**Step 5**：评论区预埋话术（5 条）

**Step 6**：输出前必须调 humanizer-zh 润色

### 红线
- [ ] 0→1 阶段不写"不接的单"
- [ ] 不写"我们专业/用心/负责"
- [ ] 正文 ≤ 500 字
- [ ] 性别中性
- [ ] 私域钩子 = 咨询导向，非收藏导向
- [ ] **必须走 humanizer-zh 润色**

## 技能 2：视觉内容设计（visual-design）

### 触发
- "配图方案 / 出图 / 设计视觉 / 写 prompt"

### 流程

**Step 1**：确定配图结构（9 图标准）
| 图号 | 功能 |
|------|------|
| 1 | 封面钩子 |
| 2-3 | 场景痛点 |
| 4-5 | 解决方案 |
| 6-7 | 信任锚点 |
| 8 | 福利/CTA |
| 9 | 品牌收尾 |

**Step 2**：每张图的视觉方案
- 场景描述、核心元素、配色、文字覆盖
- 品牌规范强制参考（见 `image-gen` skill）

**Step 3**：生成出图 prompt
- 中英双语
- 附参考图路径

**Step 4**：出图执行
- 途径优先级：豆包 > 即梦 9222 > MiniMax API
- 详见 `../../share/image-gen/SKILL.md`

### 红线
- [ ] 每张图符合品牌视觉规范（3D 软糖/暖橙/圆润）
- [ ] prompt .md 与图片同目录
- [ ] 不出人脸
- [ ] 参考图必传：logo.png + 主页背景图.png
- [ ] 封面必须有标题文字
