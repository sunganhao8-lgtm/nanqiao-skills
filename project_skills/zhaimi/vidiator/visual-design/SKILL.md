# 宅咪视觉内容设计 skill

## 触发条件

- "帮我设计配图方案"
- "这套笔记配什么图"
- "视觉设计"
- "出图方案"
- "帮我写图片 prompt"
- 写完笔记正文后需要配图

## 输入

- 笔记正文 / 脚本
- 笔记形式（图文/视频封面）
- 可选：用户对风格的偏好

## 工作流

### Step 1：分析笔记内容，确定配图结构

**图文笔记（9 图标准结构）**：
| 图号 | 功能 | 说明 |
|------|------|------|
| 图1 | 封面钩子 | 标题 + 视觉钩子，决定了打开率 |
| 图2-3 | 场景痛点 | 用户焦虑的具象化 |
| 图4-5 | 解决方案 | 干货/产品的展示 |
| 图6-7 | 信任锚点 | 过程/细节/对比证明 |
| 图8 | 福利/CTA | 价格、预约方式 |
| 图9 | 品牌收尾 | 角标+金句 |

**视频笔记（仅封面图）**：
- 1 张封面（3:4 竖图、标题+视觉钩子）

### Step 2：每张图的视觉方案

对每张图输出：
```
【图 N：{功能说明}】
场景：{一句话场景描述}
核心元素：{必须出现的主体和道具}
配色：{主色+辅色+点缀色}
文字覆盖：{文字内容+字体+颜色+位置}
参考素材引用：{是否引用 logo.png / 主页背景图.png}
风格要求：{3D 软糖/暖橙/圆润厚实/左上45°柔光}
```

### Step 3：出图 prompt 生成

每张图输出出图用的 prompt（中英双语）：
```
## Prompt
{中文 prompt（豆包/即梦用）}

## 参数
- 比例：3:4
- 参考图：logo.png + 主页背景图.png
- 风格参考：Pixar 3D, soft sunlight, warm orange tone
```

### Step 4：输出汇总

```
【宅咪视觉设计方案】
笔记标题：{标题}
出图数量：N 张

📐 出图方案总览
| 图号 | 功能 | 场景 | 核心元素 | 配色 | 文字 |
|------|------|------|----------|------|------|

📝 Prompt 清单（按顺序生成）
1. cover-{关键词}.md ↔ cover-{关键词}.png
2. card-01-{关键词}.md ↔ card-01-{关键词}.png
3. ...

🖼️ 参考素材（出图时必传）
- 宅咪 logo.png
- 宅咪主页背景图.png

⚠️ 出图后必查清单
- [ ] 每张图符合品牌视觉规范（checklist 见 §十一）
- [ ] prompt .md 与图片同目录
- [ ] 角标 宅咪 ZHAIMI 露出
- [ ] 没有 AI 画人脸
```
