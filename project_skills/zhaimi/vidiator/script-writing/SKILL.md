# 宅咪脚本写作 skill

## 触发条件

- "帮我把这个选题写成笔记"
- "写个脚本"
- "帮我出文案"
- "根据这个方向写一篇小红书"

## 输入

- 选题方向 / 关键词
- 可选：参考爆款笔记的标题/结构

## 工作流

### Step 1：确定笔记形式和信息量

- **图文**：攻略/清单/对比/科普（收藏率高）
- **视频**：过程展示/服务实拍/讲猫讲狗（信任感强）
- 不确定时默认图文（0→1 阶段图文成本更低）

### Step 2：标题设计（3 个版本，排序推荐）

每个标题标注：
- 标题原文
- 字数
- 钩子类型：{反共识 / 数字冲击 / 痛点直击 / 悬念 / 地域 / 对比 / 结果承诺}
- SEO 关键词命中
- 排序权重

**宅咪标题关键词库**：上门洗猫/上门给猫洗澡/宠物上门洗护/临港洗猫/猫洗澡应激/猫多久洗一次澡/上门洗狗/猫美容/宠物店应激

### Step 3：正文结构（500 字以内）

```
1️⃣ 开头钩子（前 2 行）— 提问/反常识/具体场景
2️⃣ 场景痛点 — "被问最多的是XXX"/"你是不是也遇到过XXX"
3️⃣ 解决方案 / 对比（干货核心）— 2-3 种情况并列
4️⃣ 宅咪怎么做（行为锚点）— 具体动作不堆形容词
5️⃣ 人设短版
6️⃣ CTA / 私域钩子（评论扣【区域+宠物】）
7️⃣ 小提醒
8️⃣ 结尾金句
```

**宅咪特有 4-6 步**：
- 4 步：用"3 公里" "10 元" "5-10 分钟"等具体数字锚定
- 6 步：私域钩子**统一格式**"评论区扣【区域+宠物】，比如'浦东·金毛'"

### Step 4：如果是视频 → 分镜表

```
| 镜号 | 时长 | 画面 | 配音 | 文字/字幕 |
```

### Step 5：配图/画面说明

- 图文版：每段文字对应的配图
- 视频版：每个分镜的场景说明

### Step 6：评论区预埋话术（5 条）

```
1. {真问题} ← 刺激互动
2. {真问题} ← 刺激互动
3. {服务话术} ← 引导私信
4. {补充信息} ← 信息增量
5. {置顶话术} ← 服务范围+福利+不催单承诺
```

**宅咪预埋问题库**：
- "我家猫认生能行吗？"
- "临港哪个小区都能去吗？"
- "价格表有吗？"
- "节假日涨价吗？"
- "需要准备什么东西吗？"

### Step 7：最终输出

```
【宅咪笔记/脚本】

📌 标题（推荐）
{标题}
备选：
1. {标题} — {理由}
2. {标题} — {理由}

📝 正文
{完整正文 ≤ 500 字}

{如果是视频：分镜表}

🖼️ 配图说明
{每张图的画面描述和风格要求}

💬 评论区预埋
{5 条话术}

⚡ 一键发布清单
- [ ] 标题确认
- [ ] 正文错别字检查
- [ ] 配图完成
- [ ] 评论区话术就绪
- [ ] 主页简介已更新
- [ ] 发布时间
```

## 后处理

产出正文后，**必须调 `humanizer-zh` skill** 进行人话润色。

## 红线

- [ ] 不写"我们专业/用心/负责"等自嗨
- [ ] 钩子用具体场景/数据/反共识
- [ ] 0→1 阶段不写"不接的单/拒客原则"
- [ ] 正文 ≤ 500 字
- [ ] 性别中性
- [ ] 团队人数弹性措辞
- [ ] **私域钩子 = 评论扣【区域+宠物】**
- [ ] **最后必须走 humanizer-zh**
