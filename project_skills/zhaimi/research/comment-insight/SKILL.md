# 宅咪评论洞察分析 skill

## 触发条件

- "帮我分析这些评论"
- "这些弹幕能出什么选题"
- "评论洞察"
- "从评论区挖选题"
- 用户给了一批评论/弹幕原文

## 输入

原始评论/弹幕/留言文本（可以是 JSONL、纯文本段落、截图里的 OCR 文本）

## 工作流

### Step 1：数据准备

如果用户没给原文：
- `mcp_chrome_devtools_*` → 抓小红书/抖音评论区
- `web_search` → 搜索相关笔记的评论
- 用户直接贴文本

### Step 2：AI 分类（每条都要过）

**宅咪专属 4 分类**（继承自 SOP-B）：

| 分类 | 典型表达 | 示例 |
|------|----------|------|
| **A. 痛点** | 我家猫/狗XXX怎么办 | "我家猫洗澡跟杀猪一样" |
| **B. 需求** | 有没有XXX服务 | "临港有人上门洗猫吗" |
| **C. 选择** | XXX和XXX哪个好 | "上门洗和宠物店洗哪个干净" |
| **D. 吐槽** | 上次去XXX太差了 | "上次去宠物店洗完猫应激了" |

每条评分两个维度 1-5：
- **痛点强度**：1=随口说 / 3=真焦虑 / 5=不解决会出问题
- **可回答度**：1=无解 / 3=有标准答案 / 5=能直接转化为宅咪服务

### Step 3：选题转化

筛选规则（SOP-B §4.2）：
- **痛点 ≥ 3 且 可回答度 ≥ 4** → 进选题池（优先）
- **痛点 ≥ 3 且 可回答度 = 3** → 进观察池
- 其余 → 存档备查

对每个进选题池的评论，生成：
- **选题标题**：改写为小红书标题
- **切入角度**：用宅咪的定位怎么回答
- **内容形式建议**：图文/视频/合集

### Step 4：输出

```
【评论洞察报告】
数据来源：{来源}
分析时间：YYYY-MM-DD HH:mm
样本量：N 条

📊 分类统计
- 痛点类：N 条（占 X%）
- 需求类：N 条（占 X%）
- 选择类：N 条（占 X%）
- 吐槽类：N 条（占 X%）
- 平均痛点强度：X.X
- 平均可回答度：X.X

🔥 选题池（痛点≥3 & 可回答度≥4）— N 条
1. 原文：{原文}
   选题标题：{改写}
   切入角度：{宅咪角度}
   推荐形式：{图文/视频}

2. ...

👀 观察池（痛点≥3 & 可回答度=3）— N 条
...

💡 本周选题推荐（Top 3）
1. {标题} — {理由}
2. {标题} — {理由}
3. {标题} — {理由}
```
