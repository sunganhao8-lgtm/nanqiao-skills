# 宅咪爆款笔记拆解 skill

## 触发条件

- "帮我拆解这个爆款笔记"
- "这篇为什么能火"
- "拉片一下这个视频"
- 用户发来爆款笔记/视频 URL

## 输入

- 爆款笔记/视频的 URL（小红书/抖音/B站/视频号）
- 或用户贴的笔记截图/描述

## 工作流

### Step 1：获取内容（工具优先级）

1. **URL 直拉**：`web_extract` 尝试获取页面内容
2. **Chrome 抓取**：`mcp_chrome_devtools_new_page` + screenshot
3. **手动描述**：URL 打不开则让用户描述

### Step 2：五维拆解

#### ②-① 标题拆解
- 标题原文 / 字数
- 钩子类型：{反共识 / 数字冲击 / 痛点直击 / 悬念 / 地域 / 对比 / 结果承诺}
- 关键词：哪些搜索词
- 标题公式：`{模板}`

#### ②-② 封面拆解
- 风格：{图文 / 真人出镜 / 宠物 / 场景}
- 配色
- 核心元素
- 文字数量和位置

#### ②-③ 钩子拆解（前 3 行 / 前 5 秒）
- 开头怎么抓注意力的
- 用了什么技巧：{提问 / 反常识 / 数据 / 场景共鸣}
- 信息差在哪里

#### ②-④ 正文/脚本结构
- 字数/时长
- 结构脉络（逐段标注功能：痛点→方案→证据→金句→CTA）
- 信息密度
- **宅咪适配方核心问题**：把"宠物医疗/干粮"换成"上门洗护"，结构还成立吗？

#### ②-⑤ 评论区洞察
- 高赞评论在聊什么
- 哪些问题是宅咪可以回答的
- 博主置顶了什么

### Step 3：爆款归因

- 核心驱动：{信息差 / 情绪价值 / 实操干货 / 场景共鸣 / 人设吸粉}
- 可复制性：{高/中/低} + 原因
- 宅电做同款要改什么
- 直接可用的素材（标题公式/结构模板/钩子模式）

### Step 4：输出

```
【爆款拆解报告】
拆解日期：YYYY-MM-DD
来源：{平台}
链接：{URL}

【标题】
原文 / 字数 / 钩子类型 / 关键词 / 公式

【封面】
风格 / 配色 / 核心元素 / 文字布局

【内容结构】
开头钩子 + 技巧
正文脉络
结尾 CTA

【评论区洞察】
高赞 1-2
待解答问题（宅咪可用）

【爆款归因】
核心驱动
可复制性
宅咪适配改动

【直接可复用】
✅ 标题公式 → 宅咪版
✅ 结构模板 → 宅咪版
✅ 钩子模式 → 宅咪版
```

## 红线

- [ ] 输出**可复用公式**，不是"这篇写得真好"
- [ ] 每部分都有宅咪适配版本
- [ ] 评论区洞察必须落实到"宅咪能回答什么问题"
