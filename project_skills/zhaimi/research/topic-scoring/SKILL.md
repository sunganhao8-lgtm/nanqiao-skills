# 宅咪选题评分 skill

## 触发条件

- "帮我看看这个选题值不值得做"
- "这个选题能火吗"
- "选题评分"
- 用户提交了宠物上门洗护/猫狗相关选题

## 输入

**宅咪专属的选题类型**：
- 上门洗护服务（"上门洗猫""上门给猫洗澡"）
- 养猫知识（"猫多久洗一次澡""猫洗澡应激"）
- 养狗知识（"小型犬怎么洗"）
- 价格/服务范围（"临港上门洗猫贵吗"）
- 场景痛点（"出差猫怎么办""搬家后猫洗澡"）
- 节日借势（"端午猫怎么办""618 上门洗猫"）

## 工作流

### Step 1：搜索量验证
- `web_search` 搜选题关键词，记录搜索结果量级、爆款笔记、时效性、长尾机会
- 评分 1-10（10=黄金赛道，1=没人搜）

### Step 2：痛点强度评估
- 焦虑程度（痒点/痛点）
- 用户会为这个痛点主动搜索吗
- 评分 1-10

### Step 3：竞争度分析
- 同赛道对手做这个选题的频次和水平
- 评分 1-10（10=没人做，1=头部垄断）

### Step 4：转化潜力评估
- 看完笔记自然的下一步（咨询/收藏/划过）
- **宅咪 0→1 钩子必选 ① 咨询导向**（评论扣【区域+宠物】）
- 评分 1-10

### Step 5：可执行度评估
- 宅咪作为服务商能不能拍/写/出
- 评分 1-10

## 宅咪业务边界检查

- [x] 跟上门洗护/宠物清洁/临港服务直接相关？
- [x] 能在笔记里自然植入宅咪服务？
- [ ] 不相关/硬蹭 → 扣 3 分

## 输出格式

```
【选题评分报告】
选题：{题目}

维度评分：
🟢 搜索量：X/10 — {说明}
🟢 痛点强度：X/10 — {说明}
🟢 竞争度：X/10 — {说明}
🟢 转化潜力：X/10 — {说明}
🟢 可执行度：X/10 — {说明}

综合评分：X/50
推荐等级：{强烈推荐 / 推荐 / 观望 / 放弃}

选题方向建议：
- {优化方向 1}
- {切入角度 1}
- {风险点提醒}

适合的笔记形式：{图文 / 短视频}
对应节日/节点：{如有}
```

## 红线

- [ ] 不写性别限定词
- [ ] 不写宅咪团队具体人数
- [ ] `date` 查当前真实日期
- [ ] 0→1 阶段钩子 = 咨询导向，不是收藏
- [ ] 不立"不接的单"（0→1 阶段）
