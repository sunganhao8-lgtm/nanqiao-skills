# 宅咪竞品内容分析 skill

## 触发条件

- "帮我分析这个账号"
- "看看竞争对手在发什么"
- "竞品分析"
- "对标账号分析"
- 用户发来对标账号链接或关键词

## 输入

竞品标识，可能是：
- 小红书/抖音账号名或链接
- 关键词（"宠物上门洗护""上门给猫洗澡""宠物美容"）
- 笔记 URL
- 一句话描述方向

## 工作流

### Step 1：赛道扫描（`web_search` + Chrome 搜索）

按以下关键词维度搜索：
- **服务类**：宠物上门洗护、上门给猫洗澡、宠物上门美容
- **宠物店/医院类**：宠物店洗澡、宠物医院美容
- **同赛道服务类**：移动宠物美容、宠物 SPA 上门
- **养宠科普类**：养猫知识、宠物清洁

记录：
- 头部玩家：粉丝量 Top 5 账号
- 腰部玩家：1w-10w 粉丝新号
- 爆款笔记：每个账号点赞 > 500 的笔记
- 内容分类

### Step 2：内容策略拆解

选 3 个最有代表性的账号（优先选低粉爆款号），拆解：
- **人设定位**：个人/团队/宠物医院/移动美容师
- **选题结构**：引流款/信任款/转化款各占多少
- **封面模板**：是否统一风格
- **标题公式**：5 个高赞标题
- **互动策略**：评论区运营
- **私域钩子**：怎么引流

### Step 3：爆款归因

对每个爆款笔记（点赞 > 500）：
- 为什么爆？信息差？情绪？干货？场景共鸣？
- 发布时间/形式/时长
- 评论区在聊什么？宅咪可以回答吗？

### Step 4：差异化机会识别

- **不做**：红海选题（头部垄断+新号没机会）
- **调整做**：有人在做好内容但可差异化
- **抢先做**：有人做了但做得不好
- **新做**：没人做但有搜索量

### Step 5：输出

```
【竞品分析报告】
分析日期：YYYY-MM-DD
分析对象：{输入关键词/账号}

一、赛道概况
- 全赛道竞争度：{高/中/低}
- 头部玩家：数量 + 策略
- 新号入局空间：{大/中/小}

二、代表性账号拆解（3 个）

【账号 1：{昵称}】
- 人设/粉丝/内容风格
- 爆款标题示例 3 个
- 爆款公式
- 私域钩子
- 蓝海选题（宅咪可复用）

【账号 2/3 同上】

三、宅咪可复用选题清单
- 🔥 优先（搜索大+差异化+宅咪能做）
  - 选题 1
  - 选题 2
- ⚡ 跟进（有人在做但能做更好）
  - 选题 3
- 👀 观察（不确定但值得测）
  - 选题 4

四、差异化建议
- {具体可执行的切入角度}
```

## 工具

- `web_search` — 主搜索
- `mcp_chrome_devtools_*` — 抓小红书/抖音公开页
- `web_extract` — 单页抽取（备选）

## 红线

- [ ] 输出**差异化机会**，不是"学习这个优秀账号"
- [ ] 所有选题建议带宅咪业务相关性判断
- [ ] 不写猜测的数据（粉丝/点赞没查到说"未获取"）
