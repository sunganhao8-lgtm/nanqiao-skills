# 宅咪标题封面检查 skill

## 触发条件

- "帮我检查这个标题"
- "封面这样行不行"
- "发布前检查"
- "标题封面检查"
- 用户写完脚本/笔记后要求审核

## 输入

- 标题（必填）
- 正文前 50 字
- 封面描述或封面图路径（可选）

## 工作流

### 第一轮：标题检查（SEO + 点击率 + 合规）

**SEO 检查**：
- [ ] 标题含有关键搜索词
- [ ] 地域词（临港/上海）适合出现
- [ ] 长度 6-20 字
- [ ] 无小红书违禁词（"第一"/"最"/"全国"）

**点击率检查**：
- [ ] 有钩子（反共识/数字/悬念/对比/结果承诺）
- [ ] 有具体承诺/信息差
- [ ] 跟同类笔记有差异化

**评分**：1-10

### 第二轮：封面检查（品牌规范符合度）

引用 `C:\Users\11390\Desktop\宅咪小红书笔记\品牌视觉规范.md`：

**品牌规范**：
- [ ] 主色 = 暖橙（#F4B860 / #E89A3C）
- [ ] 辅色 = 奶白/米色
- [ ] 3D 立体感（非平面/doodle）
- [ ] 圆润厚实（无锐角）
- [ ] 暖光场景
- [ ] 文字有 3D 阴影
- [ ] 关键数字深橙加粗
- [ ] 角标 宅咪 ZHAIMI 露出

**小红书适配**：
- [ ] 3:4 竖图
- [ ] 信息在上半部分（折叠可见）
- [ ] 非纯风景/纯猫

**评分**：1-10

### 第三轮：综合输出

```
【标题封面检查报告】
检查日期：YYYY-MM-DD

📌 标题评分：X/10
问题 → 修改建议
优化后标题：{改写}

🎨 封面评分：X/10（未提供→跳过）
问题 → 修改建议

🏁 发布就绪度：{就绪 / 小修可用 / 建议重写}
```

## 红线

- [ ] 每项问题必须有具体修改建议，不说"挺好的"
- [ ] 没有封面信息就说"未提供"
- [ ] 标题改写保留原意
- [ ] 检查后如果有修改 → 再跑一轮 humanizer-zh
